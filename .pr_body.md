## Description

M6 of the OBS-ingest PRD (#147): a reusable **subscription-gate collector** that subscribes to a broadcast over MoQT, drains its catalog and video/audio tracks, and evaluates the interop **gate** — assertable independently of a live relay. This is the last prerequisite for M5 (#154), the full ffmpeg → relay → subscribe interop test.

## Related Issue

Closes #151

## Changes

New `internal/interop` package:
- **`gate.go`** — pure gate: `Observation`, `TrackObs`, `FrameObs`, `Expectations`, `Verdict`, and `Evaluate`. Checks tracks present, codec prefixes (H.264 `avc1.` / AAC `mp4a.40.2`), dimensions, `initData`, min frame/keyframe counts, and the **B-frame-aware timestamp invariant** (PTS may regress by at most one composition-time window; DTS = decode/arrival order is monotonic by construction). No I/O, no globals.
- **`media.go`** — `readQuicVarint`, `decodeMediaFrame` (parses the `[varint ts][varint len][data]` envelope ingest emits — previously only a test helper existed), and `isAVCCKeyframe` (AVCC IDR detection, scans 4-byte length-prefixed NALUs).
- **`collect.go`** — live `Collector`: dials a relay, fetches the `"catalog"` track (`msf.ParseCatalog`), and drains each media track into an `Observation`. The live path is exercised by M5 (#154); the gate logic is unit-tested here.

## Testing

- `go test ./...` green; `go vet ./internal/interop` clean; `golangci-lint run ./internal/interop/` → 0 issues.
- Gate logic is tested **against synthetic fixtures, no live relay** (acceptance #151): well-formed stream passes; each defect (missing track, wrong codec prefix, missing `initData`, wrong dimensions, too-few frames, no keyframe, track read error, nil obs) fails with a precise reason.
- B-frame timestamp handling covered explicitly: PTS reorder **within** the CTS window passes, regression **beyond** it fails. Per acceptance, this is DTS-monotonic + PTS-bounded, not PTS-arrival-order-monotonic.
- `decodeMediaFrame` / `readQuicVarint` round-trip + error cases; `isAVCCKeyframe` (IDR, non-IDR, multi-NALU, truncated).
- `-race` left to CI (no local cgo/gcc); the gate is pure, so race is moot for it.
